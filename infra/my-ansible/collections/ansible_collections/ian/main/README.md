# ian.main

A collection for deploying the OSM infrastructure on GCP.

## Principles

- No `group_vars` / `host_vars`: values are taken from `infra/config.json`
  via the `ian.main.osm_config` lookup, and secrets are passed explicitly (`-e @secrets/vault.yml`).
- The inventory is generated by the `google.cloud.gcp_compute` plugin (see `inventory/` of the `infra/my-ansible` project).
- Role variables are prefixed with the role name and described in `meta/argument_specs.yml`.

## Structure

| Directory | Contents |
|---|---|
| `roles/` | roles (`ian.main.<role>`) |
| `plugins/lookup/` | `osm_config` — reads `config.json` |
| `plugins/filter/` | `urlsafe` — escapes secrets for URLs |
| `playbooks/` | `ian.main.site`, `deploy_binaries`, `deploy_frontend`, `issue_certificate`, `switch_backend`, `assert_project` |
