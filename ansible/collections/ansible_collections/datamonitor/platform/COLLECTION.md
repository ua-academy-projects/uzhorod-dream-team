# Data Monitor platform collection

Reusable roles for Debian-family hosts: `common`, `docker`, `connection`,
`app_source`, `compose_app`, `secret_access`, `power`, and `ops_agent`.
Roles receive explicit parameters; project configuration and service orchestration
live outside this collection.

Project setup and deployment instructions are in the
[repository README](https://github.com/ua-academy-projects/uzhorod-dream-team/blob/dmytro/btc-eth-price-analyzer/README.md).
